# 🏗️ פרקומט - מערכת תקציבים ותמחורים

> **Parkomat Budget & Pricing Management System**

מערכת ניהול תקציבים ותמחורים לקבלני התקנות של פרקומט אינטרנשיונל בע"מ.
אפליקציית ווב מתקדמת (PWA) שעובדת גם ללא חיבור אינטרנט ומאפשרת התקנה על המכשיר.

**🌐 Live:** https://[YOUR_USERNAME].github.io/parkomat-budget/

---

## ✨ יכולות עיקריות

- **📊 דשבורד מנהלי** - תצוגה חזותית של תקציבים, ניצול, חריגות
- **🏗️ ניהול פרויקטים** - 6 קטגוריות תקציב, מעקב רווחיות
- **💰 מחירונים מרובים** - A/B/C עם מכפיל אחוזי לקבלנים שונים
- **📋 בניית תמחיר** - עם שם מותאם לתמחיר (מתקן A, בקרה וכו')
- **⚠️ חריגות** - מעקב, דוחות, פילוח לפי אתר
- **📑 הצעות מחיר** - מסמך מקצועי ללקוח עם VAT 18%
- **📄 PDF + Gmail** - שליחת מסמכים דרך Gmail Compose
- **💾 אחסון מקומי** - IndexedDB (עד 50MB)
- **☁️ גיבוי ל-OneDrive** - אופציונלי (Chrome/Edge בלבד)

## 🎯 התקנה כאפליקציה

### בטלפון (Android / iOS)
1. פתח את הדף בדפדפן Chrome / Safari
2. תפריט ← **"הוסף למסך הבית"** / **"Add to Home Screen"**
3. האפליקציה תופיע כאייקון עצמאי במסך הבית

### במחשב (Chrome / Edge)
1. בפתיחת האתר, חפש סמל **⬇** ליד שורת הכתובת
2. לחץ **"התקן"**
3. האפליקציה תיפתח בחלון נפרד (כמו תוכנה)

## 💾 אחסון נתונים

**חשוב:** הנתונים נשמרים **מקומית בדפדפן** (IndexedDB). משמעות:
- כל מכשיר/דפדפן מחזיק את הנתונים שלו בנפרד
- לא קיים סנכרון אוטומטי בין מכשירים
- ניקוי נתוני הדפדפן = מחיקת הנתונים

### העברת נתונים בין מכשירים
1. **במכשיר המקור:** דשבורד ← תפריט ← ייצא נתונים (JSON)
2. העבר את הקובץ (מייל / OneDrive / WhatsApp)
3. **במכשיר היעד:** דשבורד ← תפריט ← ייבא נתונים

## 🛠️ טכנולוגיות

- Vanilla JavaScript (ES2020+) - ללא framework
- Chart.js 4.4.0 לתצוגות
- IndexedDB לאחסון מקומי
- File System Access API לסנכרון OneDrive
- Service Worker + Web Manifest (PWA)
